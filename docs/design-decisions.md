# CodeKids design decisions

CodeKids is Ahasanul Karim Khan's self-initiated portfolio concept. The latest Figma direction establishes the playful purple, pink, yellow, sky and mint language with Fredoka headings and Nunito body copy. The executable prototype preserves that direction and makes the course-comparison and trial-request task responsive.

## Decisions

- Course cards repeat the same decision attributes: suggested age, focus, example outcomes and duration.
- Purple remains the primary action color. Other accents distinguish learning paths without competing with form submission.
- The trial experience uses request language and an explicit local confirmation because no booking service exists.
- Unsupported ratings, student counts, reviews, outcomes and prices are not repeated as public evidence.
- CSS visuals replace source photography because redistribution rights were not verified.
- Desktop uses a constrained 1200 px content area; tablet balances two-column structures; mobile stacks competing actions and makes primary actions full width.

These are design intentions and implementation choices, not measured conversion or learning claims.
