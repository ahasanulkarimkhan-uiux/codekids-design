# CodeKids executable prototype tasks

## Phase 1: Foundation

- [x] **Audit source and repository**. Source: owner scope, Figma `1:2`, GitHub repository. Done when: current frame, claims, assets and repository limits are recorded. Estimate: 45 minutes.
- [x] **Define CodeKids token foundation**. Source: exact Figma values and responsive additions. Done when: separate aliased collections, targeted scopes, WEB syntax, text styles and effect style pass structural validation. Estimate: 60 minutes. (requires: source audit)
- [x] **Document owner-approved brief**. Source: current owner answers. Done when: all six Brief V3 questions, exclusions and sign-off authority are explicit. Estimate: 30 minutes.

## Phase 2: Structure

- [x] **Map the parent journey**. Source: approved primary job. Done when: every step maps to a screen/state or named external touchpoint in Markdown and HTML. Estimate: 40 minutes. (requires: brief)
- [x] **Define responsive page structure**. Source: source-frame section order and IA. Done when: semantic landmarks and section hierarchy are present without visual styling dependency. Estimate: 45 minutes. (requires: journey)

## Phase 3: Build

- [x] **Build responsive landing page**. Source: Figma `1:2`, tokens and IA. Done when: desktop, tablet and mobile layouts use tokenized HTML/CSS with no build step. Estimate: 2 hours. (requires: tokens and structure)
- [x] **Build mobile navigation and accessibility controls**. Source: non-negotiables and WCAG-aligned keyboard behavior. Done when: skip link, menu state, focus visibility, reduced motion and 44 px controls work. Estimate: 45 minutes.
- [x] **Build trial form states**. Source: owner scope. Done when: default, field-specific error, local success and reset work without network submission. Estimate: 60 minutes.
- [x] **Replace unverified imagery**. Source: asset-rights rule. Done when: public page uses only CSS visuals and existing verified repository presentation assets. Estimate: 30 minutes.

## Phase 4: Review

- [x] **Audit live required viewports**. Source: AGENTS.md six-point checklist. Done when: 1440, 834, 390, 360 and 320 px live DOM results are recorded with stress data and screenshots. Estimate: 90 minutes. (requires: deployment)
- [x] **Correct and re-audit critical defects**. Source: live audit. Done when: every squeeze, orphan, clip or overflow defect is fixed, redeployed and re-inspected. Estimate: as found. (requires: live audit)
- [x] **Publish verified atomic commit**. Source: approved delivery scope. Done when: repository, commit and GitHub Pages URL resolve and documentation matches the deployed revision. Estimate: 30 minutes. (requires: review pass)

Independent Foundation tasks could run in parallel after source discovery. Build and Review tasks remain dependency-ordered.
