FAQ

Questions before a trial request

Does my child need coding experience?

No experience is assumed in this concept. The course descriptions start from beginner-friendly activities.

Is the trial class really booked by this form?

No. This is a portfolio prototype. The form validates locally and demonstrates a confirmation state without transmitting data.

How do I choose between courses?

Start with age guidance, then compare coding style, project examples and the time commitment. A real provider should confirm placement.

Where are the student reviews and outcomes?

The source design contains proof claims, but this public prototype omits them because their redistribution and production evidence were not independently verified.
